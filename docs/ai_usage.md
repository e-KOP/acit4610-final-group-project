# AI assistance record

This is a factual development record for the ACIT4610 Final Group Project 2026 (Group-8). It records AI-assisted and AI-generated work across both required problems, based on the contributors' descriptions, source-file attribution headers, Git history and completed tests. It is **not** text for the submission report; the group must write that report itself.

**Terminology.** *AI-assisted* means AI was used during implementation, debugging, testing, review or documentation; it does not mean every line in the listed file was AI-generated. *AI-generated* is used when the contributing member or source-file header explicitly identifies the listed implementation as generated by the named tool. A passed automated test does not, by itself, establish that the full group has reviewed the code.

## Verification and limitations

- At the final local integration check on 24 November 2026, **215 automated tests passed**: 50 for Problem 1, 149 for the Problem 2 implementation/validator, and 16 for comparative analysis. Independent validators passed for all **200 Problem 1** and **450 Problem 2** saved experiments; the 11 original benchmark files passed checksum verification.
- The reported 650 experiment records, summaries and figures were produced by executing project code and were checked against saved numerical outputs. AI assistance with the code does **not** mean an AI tool fabricated those experimental measurements.
- The group should disclose the [estimated share of AI-generated or AI-drafted Python code](#ai-usage-percentage) in the submitted report. Review statuses marked pending still require group review.
- Under the assignment rules, AI may assist coding but **must not write the submitted report**. Report wording, interpretations, claims and the final AI disclosure must be written and approved by the group.

## AI usage percentage
We estimate that AI tools generated or initially drafted **about 80% of the final Python code**. Group members chose the algorithm implementations, parameter settings and experiment configurations. We reviewed, debugged and integrated the code and resolved cross-platform testing issues.
